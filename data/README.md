# Data

- `bmp/` (add the 78 thermal images here): TR20 (Mileesey) BMP files named `<nozzle °C>_<rpm>_<OFF|MID|ON>_<replicate>.bmp`. Each file carries a 256×192 radiometric temperature matrix after the pixel data.
- `bmp_data.xlsx`: manual calibration per image (scale in cm/pixel and the points clicked on the fiber and on the heater).
- `diametro_fred_por_condicion.csv`: fiber diameter per condition, from the FrED log.

The data are released under CC BY 4.0.
